# High-Concurrency Live & Offline Whisper Transcription Engine

An enterprise-grade, high-performance transcription pipeline engineered around OpenAI's Whisper model. This system bridges the gap between raw machine learning inference and high-throughput web backends by coordinating **Dynamic Request Batching**, **Acoustic Wave Stitching**, and **Stateful Sliding Token Memory Window** capabilities. 

The architecture is built natively for asynchronous `asyncio` event loops, making it capable of handling hundreds of concurrent streaming users on a single GPU without thread starvation or memory allocation crashes (OOM).

---

## 🏗️ Architectural Component Layout

1. **`UnifiedAudioEngine` (The Input Pre-Processor):** Handles structural normalization, raw binary stream buffering, and neural Voice Activity Detection (VAD) slicing.
2. **`Transcriber` (The Concurrency & Inference Orchestrator):** Manages connection lifecycles, runs the background dynamic batch gather loops, maps text/acoustic memory, and schedules unified parallel matrix forward passes on the GPU hardware.

---

## 🛠️ Detailed Component Functionality

### 1. UnifiedAudioEngine
The pipeline's gatekeeper, responsible for ingestion and formatting of all raw incoming signal formats into normalized features.

* **Multi-Format Ingestion:** Seamlessly consumes multi-channel `str` file-paths, raw `bytes` chunks from WebSockets, or localized `np.ndarray` and `torch.Tensor` structures, converting inputs smoothly into floating-point numbers.
* **Resampling & Down-mixing:** Enforces down-mixing of stereo fields into unified single mono layouts and dynamically transforms mismatching sample rates into standard 16 kHz digital signals using `torchaudio.transforms.Resample`.
* **Neural Boundary Segmentation:** Uses a localized deep-learning model (`silero-vad`) to scan audio segments. It locates physical breathing and talking patterns to isolate sentence boundaries naturally, shielding downstream inference models from processing long-form trailing dead-silences.

### 2. Transcriber
The central orchestrator designed to maximize hardware processing saturation while isolating multiple unrelated application tasks.

* **Asynchronous Thread Offloading:** Intercepts incoming requests and wraps dense model forward matrix transformations safely inside `asyncio.to_thread`. This pushes heavy mathematical loads out of the master event-loop thread, keeping the networking layer fully responsive.
* **Dual-Context Sliding Memory Windows:** Coordinates two discrete historical context frames simultaneously to drastically reduce text hallucinations:
  * **Acoustic Overlap Stitching:** Captures a 0.5-second audio wave slice from the trailing tail of the prior segment and prepends it directly onto the front of the next incoming sentence, avoiding word clipping across sudden VAD cuts.
  * **Text History Sliding Window:** Maintains an ongoing memory queue of the last 200 tokens generated by the speaker. It passes these back into Whisper's decoding layers (`prompt_ids`) via rolling negative index slices, preserving grammar consistency, pronouns, and subject matter context without crashing maximum token window limits.
* **Dynamic Request Batching Queue:** A core efficiency mechanism. It implements a global `asyncio.Queue` that acts as a pool for concurrent tasks. Instead of launching individual inference calls per user, a background consumer loop accumulates multi-user requests over a tiny timeframe (50 ms window), stacks their dimensions into a single parallelized 3D tensor block, and ships it to the GPU in a single combined execution wave.
* **Context Pre-Padding & Mask Alignment:** Resolves the problem of users possessing varying lengths of text history. It dynamically computes maximum lengths across the current concurrent pool, scales smaller rows using safety filler padding tokens (`pad_token_id`), and passes a binary `decoder_attention_mask` (0 for padding, 1 for real text) to blind attention matrices to blank slots, ensuring mathematical alignment without model degradation.
* **Decoupled Lifespan Factory (`AsyncStreamContext`):** Completely separates networking dependencies from business logic. Spawns isolated state wrappers per connected user via contextual `__enter__` and `__exit__` hooks. 
* **Residual Buffer Flushes:** Protects the pipeline against abrupt server terminations or unexpected socket closures. If a speaker abruptly drops off mid-sentence, the context teardown loop extracts the stranded raw waves from the engine, submits one final emergency pass to the queue, and extracts the last spoken phrase cleanly so no data is lost.

# ⚡ Production Benefits

* **Flattened VRAM Saturation:** Stacking entries into uniform arrays prevents GPU memory thrashing. VRAM usage remains highly flat and predictable under volatile traffic spikes.
* **Sub-200ms Latency:** Merges dynamic waiting buffers with fast matrix multiplication pipelines, ensuring transcription text strings populate instantly as soon as a human stops speaking.
* **Zero Amnesia Tracking:** Incorporating rolling historical markers guarantees that names, complex acronyms, or specific nouns maintain identical formatting and contextual spelling throughout long conversations.
